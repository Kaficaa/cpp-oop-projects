# C++ OOP Projects

Collection of object-oriented C++ projects completed during university coursework.

## Topics Covered
- Inheritance and polymorphism
- Virtual functions and abstract classes
- Dynamic memory management
- Operator overloading
- File I/O

## Projects
- **Beach Cafe Management** — manages lounge chair rentals and payments
- **Family Wallet Manager** — manages a multi-currency wallet with domestic and foreign banknotes
- **Exam Preparation Planner** — tracks study materials with difficulty ratings and time estimation
